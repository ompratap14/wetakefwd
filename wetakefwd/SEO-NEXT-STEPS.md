# WeTakeFWD search visibility

Prepared 11 October 2026. These source changes have not been deployed.

## Implemented
- Homepage title, description and visible copy focus on AI automation services in India.
- Buyer guidance explains how to choose an automation partner without inventing awards or client results.
- Organization and WebSite entities appear consistently across pages; service provider references resolve to the organization.
- Related service links connect automation, chatbots and CRM pages.
- Non-search pages and error responses carry noindex headers. The public sitemap retains the 12 existing canonical pages.

## After deployment
1. Confirm the production homepage contains the new title and text. Verify all sitemap URLs return 200 and the www HTTPS URL is the final destination; configure host-level permanent redirects for alternate domain/protocol versions if missing.
2. In the existing verified Google Search Console property, submit https://www.wetakefwd.online/sitemap.xml. Inspect the homepage and three automation service URLs, test their live versions and request indexing. An existing verification tag does not establish that this session has account access.
3. Check mobile performance with PageSpeed Insights and review Search Console Core Web Vitals. The repository describes Render Free hosting; if that is still in use, assess cold-start delays before considering a hosting change.
4. Record a baseline for non-brand queries, impressions, clicks, enquiries and landing pages. Review progress monthly, separating branded searches from AI automation service searches.
5. Publish real, client-approved case studies with the original problem, systems connected, screenshots, measurement period and verified outcomes. No invented testimonials, statistics or rankings.
6. Keep business details consistent on real company profiles. Seek relevant links through actual partnerships and useful original work, not paid ranking links.

## Content priorities
Expand the existing automation service page with a real project walkthrough first. Then add evidence-backed implementation guides covering enquiry-to-CRM workflows, chatbot human handoffs and automation cost components. Use original examples and keep each page focused on a distinct buyer question; avoid duplicate city or keyword pages.

No ranking position or indexing date is guaranteed. Useful content, technical accessibility, competition and earned reputation all matter.
