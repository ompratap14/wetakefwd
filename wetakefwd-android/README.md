# We Take Forward Android App

This is a free Android WebView wrapper for the We Take Forward website.

## Set your website URL

Edit:

`app/src/main/res/values/strings.xml`

Replace:

`https://example.com`

with your live website URL.

## Build APK in Android Studio

1. Open Android Studio.
2. Choose **Open** and select this `wetakefwd-android` folder.
3. Wait for Gradle sync to finish.
4. Go to **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the APK path after the build.

The debug APK is usually created at:

`app/build/outputs/apk/debug/app-debug.apk`
